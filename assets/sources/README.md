# Notification source icons

Monochrome source marks rendered at 48 px for a 16-point native view. AppKit tints these templates a single neutral gray; no brand colors or repository labels are shown.

GitHub, Mattermost, Gmail, Google Drive: Simple Icons (CC0-1.0), https://github.com/simple-icons/simple-icons.
Slack, ChatGPT/OpenAI, calendar, task list, meeting microphone, email, Paco paw, connected-task cloud: Tabler Icons (MIT), https://github.com/tabler/tabler-icons.

Original SVGs and upstream licenses accompany the PNGs. Brand marks remain the property of their owners. The cloud fallback deliberately does not identify an unknown MCP client as ChatGPT.
